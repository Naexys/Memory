## Features

- Picsum API fetch
- Suffle using Fisher-Yates algorithm
- Asynchronism through the use of a timer
- A11y


## Local usage

Here is how to run the website on your machine 

```bash
  git clone https://github.com/Naexys/Memory.git Naexys-Memory
  cd Naexys-Memory
```
Then find and open `index.html`
